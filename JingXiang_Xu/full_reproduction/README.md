# Independent reproduction of Li et al. (2020)

**Contributor:** Jingxiang Xu

**Scope:** Sections 5 and 7 of [*Scalable Gradients for Stochastic Differential Equations*](https://proceedings.mlr.press/v108/li20i.html), with the [complete supplement](https://proceedings.mlr.press/v108/li20i/li20i-supp.pdf).

This directory contains Jingxiang Xu's work on the stochastic adjoint, latent SDEs, and experimental integration. Section 5 defines the latent SDE model; Section 7 tests numerical gradients and latent SDEs on synthetic and motion-capture data. The resulting figures are generated here, rather than copied from the paper. [RESULTS.md](RESULTS.md) records the methods and findings; [MOCAP_AUDIT.md](MOCAP_AUDIT.md) explains why our motion-capture result differs from Table 2. The appendix, especially Sections 9.9–9.16, supplies essential model and experiment details.

An earlier [Section 3 GBM gradient check](../REPORT_SECTION.md) independently verifies the discrete Euler sensitivities, the exact GBM gradient, and TorchSDE's direct and adjoint outputs. This folder extends that check to the paper's three numerical examples and to latent SDE experiments.

## Data and implementation

- Synthetic GBM and stochastic Lorenz data are generated by `generate_data.py` with fixed seeds. Their sizes and parameters are in [data_manifest.json](outputs/data_manifest.json). The paper does not release its exact synthetic draws or weights.
- CMU subject 35 walking data use the ODE2VAE authors' preprocessed [`mocap35.mat`](https://drive.google.com/file/d/1adqzHEXaGDVObSKbJgT5HBdoZkeMZ8S3/view): 16 training, 3 validation, and 4 test sequences, each with 300 frames and 50 coordinates. Its SHA-256 is recorded in the manifest. Place it at `data/mocap35.mat`; the third-party file is excluded from Git.
- Numerical and training scripts use PyTorch and TorchSDE. Models and solver choices are stated in RESULTS.md. Checkpoints and generated `.npz` data are kept locally and excluded from Git. The plotted results and compact JSON/CSV summaries are committed.

## Run the principal experiments

First place `mocap35.mat` in `data/` as described above; `generate_data.py` checks that file while producing the shared data manifest. Then, from this directory, install `requirements.txt` and run:

```bash
python3 -m pip install -r requirements.txt
python3 numerical_study.py
python3 adaptive_study.py
python3 efficiency_study.py
python3 graph_memory_study.py
python3 supplement_examples_1_3.py
python3 generate_data.py
```

Train the synthetic models with stochastic adjoint differentiation:

```bash
python3 train_synthetic_latent_sde.py gbm --iterations 300 --batch-size 64 --adjoint --device cpu
python3 render_gbm_figure.py
mkdir -p outputs/lorenz_context1
cp outputs/lorenz_1024.npz outputs/lorenz_context1/lorenz_1024.npz
python3 train_synthetic_latent_sde.py lorenz --iterations 300 --batch-size 64 --context-dim 1 --adjoint --device cpu --output-dir outputs/lorenz_context1
python3 render_extended_lorenz.py --output-dir outputs/lorenz_context1
python3 evaluate_synthetic.py gbm
python3 evaluate_synthetic.py lorenz --output-dir outputs/lorenz_context1
python3 lorenz_mode_check.py
```

With `data/mocap35.mat` in place, reproduce the full-length mocap baseline and the two diagnostic models:

```bash
python3 train_mocap_latent_sde.py --frames 300 --iterations 400 --dt 0.02 --eval-samples 50 --adjoint --device cpu --output-dir outputs/mocap_full_400
python3 evaluate_mocap_checkpoint.py --output-dir outputs/mocap_full_400 --samples 50 --drift posterior
python3 diagnose_mocap.py --name fixedstd1_full300 --frames 300 --iterations 400 --q-logvar --fixed-observation-std 1 --adjoint --evaluation-samples 50
python3 diagnose_mocap.py --name fixedstd1_no_time_full300 --frames 300 --iterations 400 --q-logvar --fixed-observation-std 1 --no-time-input --adjoint --evaluation-samples 50
python3 evaluate_mocap_diagnostic.py outputs/mocap_diagnostics/fixedstd1_full300 --samples 50 --drift posterior
python3 evaluate_mocap_diagnostic.py outputs/mocap_diagnostics/fixedstd1_no_time_full300 --samples 50 --drift posterior
```

The full-length mocap runs select checkpoints using validation MSE, then evaluate the remaining 297 frames. The fixed-variance runs are **diagnostics**, not exact replications of the published model. Short 50-frame experiments in MOCAP_AUDIT.md are used only to identify the optimization failure; their 47-frame forecasts must not be compared with Table 2.
